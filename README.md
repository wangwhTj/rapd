# RaPD

Project website for **RaPD: Resolution-Agnostic Pixel Diffusion via Semantics-Enriched Implicit Representations**.

- Website: https://wangwhTj.github.io/rapd/
- Paper: https://arxiv.org/abs/2605.15908

## Publishing

In Settings → Pages, select **Deploy from a branch**, **main**, and **/ (root)**. No build step is required; `.nojekyll` enables plain static hosting.

## Editing

Edit `index.html`, `static/css/rapd.css`, and `static/site.js` directly. `assets/` contains displayed paper figures; `gallery/` contains gallery samples. Gallery prompts are embedded in the HTML. The abstract follows the paper source, and citation metadata was supplied by the authors.
